# TableQuest26
group project


TO RUN THE PROJECT, USE THE FOLLOWING COMMANDS IN THE TERMINAL

cd frontend
npm.cmd install  // required to bypass the Execution_Policies error - If you already installed it, you may not use the command anymore
npm.cmd run dev

Version Control Rules:
When you commit, make sure that in settings,json there is only this line: "css.lint.unknownAtRules": "ignore",
Commiting personal computer lines will conflict the project on other members' computers


For frontend design components we use Tailwind with DaisyUI on to.

To access components go to : https://daisyui.com/, and in the menu select components.
There you can browse for all neccesary components and to add them to project- select JSX tab and copy the code, then put it into JSX file that you use
